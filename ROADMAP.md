# Roadmap: модульный крафт

Чтобы начать делать полноценный модульный крафт, нужно:

- [ ] Пропарсить все рецепты.
- [ ] Распределить все компоненты по категориям (основа, дуло, магазин, шаблон, ...).
- [ ] Продумать, какой будет вид JSON-рецепта.
- [ ] Собрать модульный рецепт для каждой пушки/компонента.
- [ ] Только после всего этого думать над кодом:
  - [ ] Добавить предметам теги.
  - [ ] Добавить блок верстака и всякую косметическую часть + GUI.
    - [ ] Реализовать шаблоны разных типов оружия.
